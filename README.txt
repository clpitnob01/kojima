JAN CASEY LASTIMOSA — PORTFOLIO WEBSITE

FILES
- index.html: main portfolio page
- web-development.html: website projects gallery
- photoshop-work.html: Photoshop and image editing gallery
- counter-strike-edits.html: Counter-Strike 2 video showcase
- pc-builds-support.html: PC builds and IT support showcase

HOW TO USE
1. Keep all five HTML files in the same folder.
2. Open index.html in a browser to view the portfolio.
3. The project cards on the main page open their matching local pages.
4. Each project page currently contains media placeholders. Replace each placeholder block with your own image, video embed, or project link when ready.
5. To publish the site, upload all five HTML files together to your web host, keeping their filenames unchanged.

CONTACT
The email button on the main page still contains a placeholder email address. Replace YOUR_EMAIL@example.com with your preferred contact email before publishing.
